# System Requirements

# Системни изисквания

## Въведение

Настоящият документ описва минималните, препоръчителните и бъдещите системни изисквания за инсталиране, конфигуриране и използване на платформата **Industrial Digital Twin Platform**.

Платформата е проектирана като локална уеб базирана инженерна система, предназначена за работа в защитена вътрешна мрежа или на самостоятелна работна станция.

---

# Архитектурни изисквания

Платформата използва архитектура тип:

- Client – Server;
- Web Application;
- Local AI Processing;
- Local Database;
- Local File Storage.

Всички основни компоненти могат да бъдат разположени върху един компютър.

# Python зависимости

Всички използвани библиотеки са описани във файла:

```text
requirements.txt
```

Инсталирането се извършва чрез:

```bash
pip install -r requirements.txt
```

---

# Django

Платформата използва Django Framework.

Основното приложение се стартира чрез WSGI сървър.

По време на разработката може да бъде използван:

```bash
python manage.py runserver
```

За демонстрационна или производствена среда се препоръчва използването на Waitress.
