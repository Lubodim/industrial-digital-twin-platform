# Test Cases

# Тестови сценарии

## Въведение

Настоящият документ съдържа основните тестови сценарии (Test Cases), използвани за проверка на функционалността на **Industrial Digital Twin Platform**.

Всеки тестов сценарий съдържа:

- уникален идентификатор;
- описание;
- предварителни условия;
- последователност от действия;
- очакван резултат.

Тестовите сценарии покриват основните функционални модули на платформата.

---

# TC-001 Вход в системата

## Цел

Проверка на успешен вход.

### Предварителни условия

- Съществува валиден потребител.
- Платформата е стартирана.

### Стъпки

1. Отворете страницата за вход.
2. Въведете потребителско име.
3. Въведете парола.
4. Натиснете **Вход**.

### Очакван резултат

Потребителят успешно влиза в системата и се зарежда началната страница.

---

# TC-002 Неуспешен вход

## Цел

Проверка на защитата при невалидни данни.

### Стъпки

1. Въведете грешно потребителско име.
2. Въведете грешна парола.
3. Натиснете **Вход**.

### Очакван резултат

Показва се съобщение за неуспешно удостоверяване.
