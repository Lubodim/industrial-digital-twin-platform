# Environment Variables

# Променливи на средата

## Въведение

Настоящият документ описва всички използвани променливи на средата (Environment Variables) в **Industrial Digital Twin Platform**.

Използването на Environment Variables позволява чувствителната информация и конфигурационните параметри да бъдат отделени от програмния код. По този начин проектът може безопасно да бъде публикуван в GitHub без риск от разкриване на API ключове, пароли и други конфиденциални настройки.

Всички променливи се съхраняват във файла:

```text
.env
```

който се намира в основната директория на проекта.

---

# Зареждане на променливите

При стартиране на приложението Django зарежда автоматично стойностите от файла `.env`.

Те се използват от:

- Django Configuration;
- External AI Services;
- Local AI;
- Security Settings;
- Development Configuration.

---

# Структура на .env файла

Примерна структура:

```text
SECRET_KEY=your-secret-key

DEBUG=True

ALLOWED_HOSTS=127.0.0.1,localhost

OPENAI_API_KEY=

ANTHROPIC_API_KEY=

GEMINI_API_KEY=

GROK_API_KEY=

OLLAMA_MODEL=llama3
```

---

# SECRET_KEY

Описание

Уникален криптографски ключ, използван от Django.

Пример:

```text
SECRET_KEY=django-insecure-xxxxxxxxxxxxxxxxxxxxxxxx
```

Използва се за:

- защита на потребителските сесии;
- криптографско подписване;
- CSRF защита;
- сигурност на приложението.

---

# DEBUG

Описание

Определя режима на работа на приложението.

Стойности

```text
DEBUG=True
```

или

```text
DEBUG=False
```

При разработка се използва:

```text
True
```

При производствена среда:

```text
False
```

---

# ALLOWED_HOSTS

Описание

Списък с позволените адреси, чрез които приложението може да бъде достъпвано.

Пример

```text
ALLOWED_HOSTS=127.0.0.1,localhost,industrial.dtp
```

---

# OPENAI_API_KEY

Описание

API ключ за OpenAI.

Използва се при външния AI анализ.

Пример

```text
OPENAI_API_KEY=sk-xxxxxxxxxxxxxxxx
```

При липса на ключ OpenAI анализът автоматично се пропуска.

---

# ANTHROPIC_API_KEY

Описание

API ключ за Anthropic Claude.

Пример

```text
ANTHROPIC_API_KEY=xxxxxxxxxxxxxxxx
```

При липса на ключ Claude не участва във външния анализ.

---

# GEMINI_API_KEY

Описание

API ключ за Google Gemini.

Пример

```text
GEMINI_API_KEY=xxxxxxxxxxxxxxxx
```

---

# GROK_API_KEY

Описание

API ключ за xAI Grok.

Пример

```text
GROK_API_KEY=xxxxxxxxxxxxxxxx
```

---

# OLLAMA_MODEL

Описание

Определя кой локален езиков модел ще използва платформата.

Пример

```text
OLLAMA_MODEL=llama3
```

Възможно е използването и на други модели, предварително инсталирани в Ollama.

---

# Незадължителни променливи

При бъдещо развитие могат да бъдат добавени допълнителни настройки, например:

```text
DATABASE_URL=
```

```text
LOG_LEVEL=
```

```text
DEFAULT_LANGUAGE=
```

```text
MEDIA_ROOT=
```

```text
STATIC_ROOT=
```

---

# Работа без външен AI

Ако всички API ключове останат празни:

```text
OPENAI_API_KEY=

ANTHROPIC_API_KEY=

GEMINI_API_KEY=

GROK_API_KEY=
```

платформата продължава да работи нормално чрез локалния AI анализ с Ollama.

---

# Сигурност

Файлът `.env` съдържа чувствителна информация.

Поради тази причина:

- не трябва да бъде качван в публичен GitHub репозиторий;
- трябва да бъде включен в `.gitignore`;
- трябва да бъде архивиран отделно от сорс кода.

---

# Добри практики

Препоръчва се:

- използване на различен `SECRET_KEY` за всяка инсталация;
- използване на `DEBUG=False` в производствена среда;
- редовна подмяна на API ключовете;
- ограничаване на достъпа до файла `.env`;
- архивиране на конфигурацията.

---

# Проверка на конфигурацията

След промяна на Environment Variables се препоръчва:

1. рестартиране на приложението;
2. проверка на входа в системата;
3. проверка на външните AI услуги;
4. проверка на локалния AI анализ;
5. проверка на 3D визуализацията.

---

# Заключение

Използването на Environment Variables осигурява сигурен и гъвкав начин за конфигуриране на **Industrial Digital Twin Platform**. Отделянето на чувствителната информация от програмния код улеснява разработката, повишава сигурността и позволява лесно разполагане на платформата в различни среди без необходимост от промени в сорс кода.
